# EventEase-Client-Main
EventEase is a modern, responsive React application designed for seamless event discovery and booking. It enables users to browse, search, and reserve events with secure Stripe payments, wallet cashback, and real-time chat. Built using React, Tailwind CSS, Redux Toolkit, and Axios.
# EventEase Frontend 🎉

The frontend of **EventEase**, a modern event booking platform where users can discover events, search with filters, and book tickets with Stripe integration and wallet cashback.

## 🚀 Features
- 🔍 Search and filter events dynamically
- 💳 Stripe integration for secure payments
- 💰 Wallet points system with cashback rewards
- 📍 Google Maps link for event locations
- 💬 Real-time Chat for event communities
- 🖼️ Cloudinary-based image handling
- 📱 Responsive design with TailwindCSS
- ⚡ State management via Redux Toolkit
- 🔐 Authentication & role-based access

## 🛠️ Tech Stack
- React.js
- Tailwind CSS
- Redux Toolkit
- Axios
- React Router DOM
